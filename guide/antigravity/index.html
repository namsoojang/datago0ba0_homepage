▣ 안티그래비티 IDE란 무엇이고 왜 좋은가?

웹 브라우저로 챗GPT나 클로드에 접속하여 질문할 때는 내가 소스 코드를 복사해서 채팅창에 붙여넣고, AI가 작성해 준 코드를 다시 복사해서 내 에디터로 가져와 붙여넣는 번거로운 반복 작업을 해야 합니다.

안티그래비티 IDE는 내 로컬 컴퓨터의 특정 프로젝트 폴더에 직접 접근하여 파일을 수정하고, 터미널 명령어를 내려 코드를 컴파일하고 오류가 나면 스스로 디버깅하는 능동형 AI 에이전트 개발 도구입니다. 말 그대로 대화만 하면 알아서 내 하드디스크의 파일을 직접 깎고 다듬어 주어, 코딩 및 자동화 작업의 단순 수작업 단계를 완전히 제거해 줍니다.

■ 일반 안티그래비티 vs 안티그래비티 IDE의 명확한 차이점

  • 일반 안티그래비티(웹 비서 도구) : 브라우저나 시스템 알림창 등에서 구동되는 일반 비서형 대화 도구입니다. 간단한 이메일 작성 보조나 RPA 알림 연동 및 가벼운 질의응답을 할 때 주로 사용됩니다.
  • 안티그래비티 IDE(통합 개발 환경) : 실제 소스 코드를 분석하고 프로그래밍 작업을 처리하기 위해 전문 텍스트 에디터와 내부 터미널이 한 창에 통합되어 구동되는 도구입니다. 실무 데이터 분석 코드를 작성하거나 깃허브 원격 저장소와 연동하여 커밋을 수행하는 등의 진짜 코딩 비서로 활용하려면 반드시 이 안티그래비티 IDE 패키지를 설치해 주셔야 합니다. (설치하실 때 이 두 도구를 혼동하기 쉬우니 목적에 알맞게 IDE 버전을 다운받아 실행하셔야 합니다,,)
▣ 1. 안티그래비티 IDE 설치

안티그래비티 IDE 패키지는 독립된 윈도우 인스톨러(.exe) 형태로 배포되어 다운로드 후 즉시 설치하실 수 있습니다.

▲ 공식 사이트 내 다운로드 버튼 클릭 경로 확인
  • 안티그래비티 공식 다운로드 페이지(https://antigravity.google/product/antigravity-ide)에 접속합니다.
  • 화면 중앙의 'Download' 단추를 클릭하여 설치 파일을 내려받습니다.
  • 다운로드 완료 후 인스톨러 파일을 기동하여 설치를 마치며, 윈도우 보안 경고 시 추가 실행을 승인해 줍니다.
  • 기본 런타임 연결 알림 팝업창에서 자동 구성을 승인하면 정상적으로 설치 작업이 마쳐집니다.
▣ 2. 안티그래비티 화면 설명

안티그래비티의 내부 화면은 사용자가 에이전트와 대화를 나눔과 동시에 소스코드와 결과물을 한눈에 제어하도록 4개의 핵심 분할 패널로 나뉘어 있습니다.

▲ 안티그래비티 IDE의 기본 분할 패널 구성도 (① 파일 트리, ② 코드 에디터, ③ 내부 터미널, ④ 에이전트 대화창)
  • ① 파일 탐색기 (Explorer Panel) : 현재 워크스페이스에 열린 프로젝트 파일들을 계층 트랙 형태로 파악하는 공간입니다.
  • ② 에디터 작업 공간 (Editor Panel) : 내가 연 소스 파일을 직접 눈으로 읽거나 개별적으로 텍스트를 입력하여 편집하는 에디터 창입니다.
  • ③ 샌드박스 터미널 (Terminal Panel) : 에이전트가 실행하는 명령어나 직접 동작시킬 빌드/테스트 스크립트의 작동 상태를 모니터링하는 내부 셸입니다.
  • ④ 에이전트 대화창 (Agent Panel) : 인공지능 에이전트와 페어 프로그래밍을 위해 요구사항을 지시하고, 수행 중 발생하는 에러를 토론하는 핵심 소통 채널입니다.
▣ 3. 작업 워크스페이스 폴더 지정 방법

안티그래비티 에이전트가 내가 원하는 범위 밖의 윈도우 시스템 파일을 건드리지 않고, 지정된 장소 안에서만 안전하게 일하게 하려면 작업 폴더(Cwd) 지정을 해주어야 합니다.

▲ 신규 폴더를 로드할 때 에이전트 구동 허용을 위한 신뢰 버튼 확인
  • 화면 좌측 최상단의 주 메뉴에서 [File] -> [Open Workspace] 메뉴를 클릭합니다.
  • 내가 작업하고자 하는 대상 로컬 폴더(예: C:/Users/장남수/Documents/00_데이터공방/1_Project/메세지배달부)를 선택하여 열기를 완료합니다.
  • 에이전트 구동 시작 시 폴더 읽기 및 파일 생성 권한 요구 팝업창이 나타나면 반드시 'Yes, I trust the authors' 버튼을 클릭해 주셔야 샌드박스가 정상 기동합니다.
▣ 4. LLM 모델 지정 및 질문 방법

어려운 비즈니스 분석인지, 단순 반복적인 맞춤법 교정인지에 따라 에이전트의 중심 두뇌인 대형 언어 모델을 전환하여 사용할 수 있습니다.

▲ 대화창 내부의 탑재 모델 선택 목록
▲ 골뱅이(@) 키를 활용한 파일 참조 기능
  • 질문 입력창 우측 하단의 선택 바를 클릭하여 작업 목적에 맞춘 전용 모델로 교체할 수 있습니다.
  • Gemini 3.5 Flash (Medium) : 단순 오타 교정, 스크린샷 크기 조절 스크립트 작성 등 응답 시간과 고속 처리가 최우선일 때 선택하면 엄청나게 신속합니다.
  • Gemini 3.5 Pro (Large) : 아키텍처 의사결정, 구글 스토어 개인정보 선언문 대조 등 고도로 정교한 인과 관계 해석과 장문 문맥 이해가 필요할 때 선택하면 유효합니다.
  • 골뱅이 기호(@)를 입력하고 파일명을 연달아 치면, 특정 파일(예: @project.md)의 컨텍스트를 에이전트 대화창에 간편하게 직접 주입하여 질의할 수 있습니다.
▣ 5. md 파일을 활용한 업무 요청 및 지시 방법

AI가 기계적인 실수를 하거나 비즈니스 규칙에서 벗어나는 것을 차단하는 데이터공방의 핵심 노하우는 바로 마크다운 지시문(SOP)을 에이전트에게 물려주는 설계입니다.

  • 워크스페이스 디렉토리 하위에 'directives' 폴더를 만들고, `SOP_글쓰기지침.md` 같은 마크다운 문서를 작성합니다.
  • 문서 본문 내에 절대로 쓰지 말아야 할 금지 리스트(마크다운 볼드 기호 사용 금지 등)나 데이터 매핑 제약조건을 일반 텍스트 규칙으로 촘촘하게 채워 적어둡니다.
  • 에이전트 대화창에 `@SOP_글쓰기지침.md 의 규칙을 뼈대로 삼아서 아래 내용을 초안으로 다듬어줘` 형태로 지시를 내리면, 확률적 오작동을 차단하고 높은 일관성을 보장받을 수 있습니다.
▣ 6. 코덱스(Codex)를 익스텐션으로 연결하는 방법

코덱스는 빌드 성공 여부를 로컬에서 자동 검사하고, 문법 규칙 위반(Lint Error)을 사전 필터링하여 무결성 있는 코드만 깃허브 원격 저장소에 커밋하도록 통제해 주는 도구입니다.

▲ 익스텐션 탭에서 Codex 플러그인 검색 및 설치 버튼 확인
  • IDE 왼쪽 바에 있는 네모난 퍼즐 아이콘의 [Extensions] 패널을 활성화합니다.
  • 검색창에 'Codex'를 입력하고 정식 제공 플러그인을 찾아 설치 버튼을 클릭합니다.
  • 설치 후 나타나는 연동 창에서 본인의 깃허브 계정 인증을 처리하여 권한 빗장을 엽니다.
  • 세팅이 끝나면 프로젝트에 `.codexrc` 파일이 자동으로 안착하게 되며, 이제 실시간 코드 안전 검사와 깃 최신화가 한 루프로 안전하게 보장됩니다.
▣ 7. 클로드 코드(Claude Code) 터미널 연동 방법

클로드 코드는 Anthropic사에서 제공하는 초고속 터미널(CLI) 기반 AI 개발 에이전트 도구입니다. 안티그래비티는 내부 셸 터미널을 통해 이 클로드 코드를 전역 런타임 비서로 쉽게 병렬 연결하여 개발 환경의 시너지를 극대화할 수 있습니다.

■ 선수 조건: Node.js 및 npm 설치

  • Node.js 공식 웹사이트(https://nodejs.org/)에 접속합니다.
  • 대부분의 사용자에게 안정적으로 권장하는 LTS(Long Term Support) 버전 인스톨러를 다운로드합니다.
  • 다운로드한 셋업 파일을 실행하고 다음(Next)을 계속 클릭하여 설치를 완료합니다.
  • 설치가 끝난 뒤, 환경변수를 반영하기 위해 안티그래비티 IDE 프로그램을 완전히 종료했다가 재부팅합니다.
  • 안티그래비티 하단 터미널(Terminal)에 node -v 및 npm -v를 입력하여 버전 숫자가 정상 확인되는지 검증합니다.
  • 안티그래비티 IDE 하단의 터미널(Terminal) 탭을 활성화합니다.
  • 터미널 명령창에 아래의 npm 전역 설치 코드를 입력하고 실행하여 모듈을 내려받습니다:
    npm install -g @anthropic-ai/claude-code
  • 설치가 끝나면 터미널 창에 claude를 쳐서 구동한 후, 터미널창에 표시되는 원타임 보안 링크에 접속하여 Anthropic 계정 로그인을 처리해 줍니다.
  • 인증 연동이 완수되면 이제 터미널 창에서 클로드 코드가 대기 상태에 접어들며, 안티그래비티 창에 로드된 소스 코드들을 터미널 내부에서 동시에 직접 훑어보며 코딩하는 무결점 AI 협업 루프가 구축 완료됩니다.

▷ 꿀팁: 터미널 창을 우측으로 배치하여 AI 대화창처럼 쓰기

하단 터미널 패널의 탭을 마우스 우클릭하거나 우측 아이콘을 클릭하여 간편하게 오른쪽 세로 화면으로 보낼 수 있습니다. 이렇게 배치하면 제미나이나 코덱스 채팅 패널처럼 세로형 메인 AI 비서 느낌으로 넓고 편안하게 사용하실 수 있습니다.

▲ 탭 우클릭 후 Panel Position -> Right 선택
▲ 우측으로 고정 정렬이 완료된 터미널 레이아웃
  • 안티그래비티 하단 터미널(Terminal) 탭 이름을 마우스 우클릭합니다.
  • 컨텍스트 메뉴 창이 나타나면 [Panel Position] -> [Right] (또는 Move Panel to Right)를 클릭합니다.
  • 또는 터미널 패널 영역 우측 맨 끝 상단에 있는 미니 버튼(창 분할 형태의 레이아웃 변경 단추)을 직접 클릭하셔도 즉시 오른쪽 세로축으로 안착됩니다.
  • 터미널창이 오른쪽에 길게 고착(Docking)되면서, 왼편에는 코드를 띄우고 오른편에는 클로드 코드 명령창을 길게 늘어뜨려 소통하는 환상적인 좌우 2분할 뷰가 완성됩니다. (되돌리려면 다시 터미널 탭을 우클릭하여 [Move Panel to Bottom]을 누르면 됩니다,,)
