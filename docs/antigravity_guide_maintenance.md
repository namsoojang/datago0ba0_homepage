# Antigravity 가이드 운영 메모

이 문서는 홈페이지 방문자가 아닌 콘텐츠 관리자와 유지보수 담당자를 위한 내부 운영 문서입니다.

## 단일 원본

`docs/antigravity_guide.md`를 Antigravity 시작 가이드의 내용 단일 원본으로 사용합니다.

- 홈페이지: `guide/antigravity/index.html`이 Markdown 제목, 목록, 표와 이미지 경로를 읽어 렌더링합니다.
- PDF: 동일한 Markdown 원고를 기준으로 제작합니다.
- 이미지: `assets/images/guide/`에서 공동 사용합니다.
- 사실 검증: 각 절의 공식 근거 링크를 기준으로 정기 점검합니다.
- 버전 관리: 작성일과 공식 문서 검증일을 분리해 기록합니다.

홈페이지와 PDF용 문장을 따로 복사해 관리하지 않습니다. 내비게이션, CTA, 다운로드 폼처럼 표현 계층에만 필요한 요소는 홈페이지 템플릿에 둡니다.
