# 데이터공방 블로그 발행 체크리스트 (Blog Publishing Checklist)

데이터공방 공식 홈페이지의 초경량 블로그 시스템에 새로운 칼럼이나 출강 후기, 개발 일지를 발행할 때 누락을 방지하고 장남수님만의 따뜻하고 전문적인 글쓰기 스타일을 유지하기 위한 단계별 가이드라인입니다.

---

## 1단계: 본문 기획 및 스타일링 (Tone & Manner)

글을 작성하기 전과 초안 교정 시에 반드시 아래 항목들을 체크해 장남수 페르소나가 자연스럽게 녹아들게 합니다.

▣ 번역투 표현 배제
- 조사 번역투 (~에 있어서, ~에 대해, ~를 필요로 하다 등) 제거.
- ~할 때, ~에 관한, ~가 필요합니다 와 같은 구어체 입말로 순화.
- 이중 피동이나 번역식 피동 (~되어지다, ~에 의해) 제거하고 능동 표현 적용.

▣ 문체와 레이아웃 규칙
- 기계적인 첫째, 둘째, 셋째 와 같은 형식 배제.
- 결론적으로, 시사하는 바가 크다, 혁신적인 과 같은 AI 상투 관용구 제거.
- 독자에게 정보를 주는 곳에서는 정중한 경어체 (~합니다, ~했네요) 사용.
- 개인 소회나 위트 있는 고백은 괄호 () 속 독백체 (~함!, ~해야지!)를 자연스럽게 섞어 인간미 부여.
- 텍스트 가독성을 위해 마크다운 볼드 기호 (별표 두 개) 사용 금지 (줄바꿈, 텍스트 기호, 제목 구분을 적극 사용).
- 모든 종류의 그림 이모지 사용 금지 (텍스트 특수 기호 ▣, ■, ▲, ▷ 등으로 대체).

---

## 2단계: 에셋 및 마크다운 파일 준비

▣ 썸네일 이미지 준비
- 경로: assets/images/blog/ 하위에 썸네일 파일 배치.
- 확장자: png 또는 jpg 권장.
- 파일명: 영문 소문자와 하이픈(-) 조합 권장 (예: my_new_post_cover.png).

▣ 본문 마크다운 파일 생성
- 경로: data/posts/ 하위에 {id}.md 형식으로 파일 생성.
- 파일명 예시: ref-11.md (기존 포스팅 id 흐름을 파악하여 순차 부여).
- 작성 문법: marked.js 파서와 Prism.js 코드 하이라이터가 정상 동작하도록 코드블록 시작 시 언어 지정 명시 (예: ```javascript).

## 3단계: JSON 메타데이터 등록

새 글이 블로그 목록에 정상 노출되고 검색엔진 및 SNS 공유 최적화가 이루어지도록 data/posts.json 최상단에 데이터를 추가합니다. (최신 글이 목록 가장 위에 오도록 배열의 맨 앞에 삽입)

▣ posts.json 신규 레코드 양식
```json
  {
    "id": "ref-11",
    "title": "여기에 포스팅 제목을 입력하세요",
    "date": "YYYY-MM-DD",
    "category": "출강후기",
    "tags": ["태그1", "태그2", "태그3"],
    "summary": "블로그 목록 카드 및 SNS 공유 시 노출될 2~3줄 요약 설명글을 작성합니다.",
    "thumbnail": "./assets/images/blog/썸네일파일명.png",
    "contentPath": "data/posts/ref-11.md"
  }
```

▣ 카테고리(category) 선택 기준
- blog-handler.js 필터와 호환되는 아래 3가지 카테고리 중 하나를 정확히 입력합니다:
  - 출강후기
  - 교육칼럼
  - 개발일지

---

## 4단계: 로컬 검증 및 배포

▣ 로컬 서버 환경 테스트
- 로컬 터미널에서 파이썬 간이 서버 가동:
  python -m http.server 8000
- 브라우저로 http://localhost:8000/blog.html 접속.
- 신규 글이 목록 최상단에 올바른 썸네일, 날짜, 카테고리와 함께 등장하는지 확인.
- 카드를 클릭해 blog-detail.html 상세 보기 페이지로 진입하여 본문 마크다운 렌더링 상태 확인.
- 브라우저 개발자 도구(F12) 콘솔 탭을 열어 404 Not Found 또는 JS 파싱 에러가 발생하지 않는지 최종 점검.

▣ 배포 실행
- 변경 내용을 Git에 커밋하고 원격 저장소에 반영합니다:
  git status
  git add .
  git commit -m "feat: 블로그 신규 칼럼 발행 (포스트 ID)"
  git push
