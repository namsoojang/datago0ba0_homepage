# 실무 가이드 정보구조 및 CRM 운영 메모

이 문서는 홈페이지 관리자용 메모이며 공개 가이드 본문에는 포함하지 않습니다.

## 정보구조

```text
홈페이지
└── Guide
    └── 가이드 허브
        ├── STEP 01 Antigravity 실무 시작
        │   ├── 웹 가이드
        │   └── PDF
        ├── STEP 02 Rules & Skills 설계
        │   ├── 웹 가이드
        │   └── PDF
        └── STEP 03 팀 적용
            ├── 교육·도입 상담
            └── 적용 사례
```

두 문서는 독립 콘텐츠가 아니라 `도구 시작 → 업무 표준화 → 조직 적용`의 연속된 여정으로 안내합니다.

## CRM 원칙

- PDF 다운로드를 필수 개인정보 입력으로 막지 않는다.
- 상담 폼은 PDF 다운로드와 분리하고 사용자의 명확한 의도로 받는다.
- 첫 접점에서는 이메일만 필수로 하고 이름과 조직명은 선택으로 둔다.
- 관심 분야를 `사내 교육`, `업무 자동화`, `Rules/Skills 설계`, `기타 협업`으로 구분해 후속 응답 맥락을 확보한다.
- 개인정보 수집·이용 동의와 개인정보처리방침 링크를 폼 가까이에 둔다.
- 각 가이드의 마지막 CTA는 다음 학습 단계 또는 팀 적용 상담으로 연결한다.

## 권장 측정 이벤트

| 이벤트 | 의미 | 주요 속성 |
|---|---|---|
| `view_guide_hub` | 가이드 허브 방문 | 유입 페이지 |
| `select_guide_step` | 단계별 가이드 선택 | `step`, `guide_name` |
| `download_guide_pdf` | PDF 다운로드 | `guide_name` |
| `submit_antigravity_guide_consultation` | 상담 폼 완료 | `use_case` |
| `click_team_consultation` | 팀 적용 CTA 선택 | `source_guide` |

## 우선 확인할 지표

1. 홈페이지 방문 대비 가이드 허브 진입률
2. 허브 방문 대비 STEP 01·02 선택 비율
3. 웹 가이드 방문 대비 PDF 다운로드율
4. 가이드 방문 대비 상담 CTA 클릭률
5. 상담 CTA 클릭 대비 폼 완료율

GA4 이벤트가 아직 구현되지 않은 항목은 배포 후 실제 분석 요구와 기존 이벤트 명명 규칙을 확인한 뒤 추가합니다.
