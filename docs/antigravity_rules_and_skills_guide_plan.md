# Antigravity IDE 룰 및 스킬 실무 가이드 기획안

이 기획안은 안티그래비티 IDE의 양대 핵심 기능인 룰(Directives)과 스킬(Skills)의 실무적 가치를 조명하고, 사용자들이 AI 호출 비용(토큰)을 절감하면서도 100% 일관된 데이터 분석 성과를 얻을 수 있도록 돕는 실용 가이드북 제작을 목적으로 합니다. 


---

## ▣ 1. 룰(Rules / Directives)이 필요한 이유와 상황

룰은 에이전트의 작동 방식을 명시하는 업무 매뉴얼 역할을 수행합니다.

* 일관된 퀄리티의 결과물 보장
  AI는 확률 모델에 기반해 구동되므로, 동일한 지시를 내려도 매번 코드 스타일, 테이블 구조, 보고서 서식이 불규칙하게 흔들립니다. 룰을 지정해 두면 언제 호출하든 사내 템플릿과 분석 규격에 딱 맞춰진 100점짜리 일관된 코드와 글이 출력됩니다.
* 결과물 고도화 및 고급 제약사항 강제
  단순 질문으로는 빠뜨리기 쉬운 데이터 분석 규칙(예: 차트 시각화 시 한글 깨짐 방지 폰트 연동, 분석 도중 발생하는 불필요한 Warning 메시지 숨김 등)을 에이전트의 컨텍스트에 락(Lock)을 걸어 안정적으로 수행하게 합니다.

---

## ▣ 2. 룰 작성 및 적용하는 방법 (안티그래비티 IDE에서)

안티그래비티 IDE 환경 내에서 룰을 손쉽게 작성하고 에이전트에게 전송하는 프로토콜입니다.

* 작성 위치
  작업 워크스페이스(Cwd) 루트 디렉토리 하위에 directives/ 폴더를 생성합니다.
* 파일 포맷 및 작성법
  directives/SOP_데이터전처리.md 와 같이 확장자가 .md 인 마크다운 문서로 상세 규칙들을 작성해 둡니다. 표(Table)나 개조식 리스트 형태로 작성 시 에이전트가 가장 정확히 인식합니다.
* 적용 방법
  대화창에 질문할 때 골뱅이(@) 기호를 입력하고 지침서 파일명을 참조로 붙여 질문합니다.
  예시: @SOP_데이터전처리.md 지침서에 맞춰서 아래 매출 현황 csv 데이터를 요약 분석해줘.

---

## ▣ 3. 스킬(Skills)을 쓰면 좋을 상황

스킬은 에이전트가 직접 실행할 수 있는 특수 도구 또는 실행 코드 모음을 의미합니다.

* 토큰 수(비용) 절감
  매번 질문할 때마다 수십에서 수백 라인에 달하는 복잡한 데이터 가공 및 파일 정제용 코드를 프롬프트로 기재하여 전송하면, AI가 매 응답 시 해당 컨텍스트를 입력 토큰으로 소비하여 큰 비용을 유발합니다. 이 로직을 modules/ 폴더에 스크립트 스킬로 이식해 두면 단 한 줄의 터미널 호출 명령어로 끝나므로 토큰 요금을 90% 이상 아낄 수 있습니다.
* 프롬프트 반복 입력 예방
  주기적으로 수행하는 동일하고 긴 데이터 변환 프로세스(예: 데이터 로드 ➡️ 날짜 포맷 변환 ➡️ 결측치 평균값 대체 ➡️ CSV 내보내기)를 매번 질문창에 타자 쳐서 설명할 필요가 없어지므로 단순 수작업 지시가 차단됩니다.

---

## ▣ 4. 스킬 작성 및 적용 방법 (안티그래비티 IDE에서)

안티그래비티 IDE 내에 스킬을 빌드하고 에이전트에게 구동시키는 조작 절차입니다.

* 작성 위치
  워크스페이스 루트 하위에 modules/ 폴더를 생성합니다.
* 파일 포맷 및 작성법
  modules/data_cleaner.py 와 같이 실제로 터미널 셸(Shell)에서 구동 가능한 파이썬 또는 자바스크립트 소스코드 파일로 데이터 연산 및 변환 작업을 결정론적으로 작성해 둡니다.
* 적용 방법
  대화창에 에이전트를 향해 modules/data_cleaner.py 스킬을 구동하여 엑셀 원본 데이터를 정제해줘 라고 지시하면, 에이전트가 내부 터미널 셸을 통해 해당 파이썬 스크립트를 물리적으로 즉시 자동 구동합니다.

---

## ▣ 5. 이럴 때는 룰을, 이럴 때는 스킬을 사용하세요! (상황별 입력 예시)

실무자가 즉각 참고할 수 있는 적용 매핑 및 질의응답 세트입니다.

* 상황 1: 보고서 결론 도출 및 스타일 가이드라인을 강제하고 싶을 때 ➡️ 룰 사용
  * 예시: 보고서 테이블의 금액 단위는 항상 만원 단위로 쉼표를 찍어 표기하고, 요약글은 개조식으로 3줄만 작성해줘 (directives/report_format.md)
* 상황 2: 반복적이고 긴 파이썬 데이터 전처리와 파일 입출력을 빠르게 처리하고 토큰을 아끼고 싶을 때 ➡️ 스킬 사용
  * 예시: modules/cleaner.py 파일 실행해서 이번 주 고객 데이터에서 중복 행 지우고 날짜 포맷팅해줘
* 상황 3: 룰과 스킬의 환상적인 융합 (시너지 예시)
  * 예시: 데이터 분석 프로세스는 modules/ 스킬로 터미널에서 고속 실행하고, 최종 화면 출력 톤앤매너와 시각화 폰트 컨벤션 규칙은 directives/ 룰로 묶어서 가이드하는 프로 레벨 콤보 제안
