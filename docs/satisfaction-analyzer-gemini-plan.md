## 1. 목표

데이터공방 홈페이지의 RPA 도구 모음에 `만족도 분석 & 보고서 생성기`를 추가한다.

1차 버전은 서버, 로그인, Google Sheets 연동 없이 브라우저 안에서만 동작한다. 사용자는 표 데이터를 붙여넣거나 CSV 파일을 업로드하고, 도구는 만족도 설문 결과를 자동 분석해 요약 지표와 문항별 시각화를 보여준다.

## 2. 결정된 범위

### 포함

- 표 데이터 붙여넣기
- CSV 파일 업로드
- 브라우저 로컬 분석
- 1~5점 척도 문항 자동 탐지
- 주관식 문항 자동 탐지
- 개인정보 가능 컬럼 감지 및 분석 제외 후보 표시
- 전체 요약 지표
- 문항별 평균 점수
- 문항별 1~5점 분포 시각화
- 주관식 응답 목록
- 보고서용 요약 텍스트 복사
- 분석 결과 CSV 다운로드

### 제외

- Excel XLSX 업로드
- XLSX 보고서 다운로드
- Google Sheets 직접 연동
- FastAPI 서버 이식
- 대시보드 로그인 또는 인증
- 강사용 공유보드
- 이메일 발송
- 원본 데이터 서버 저장

## 4. 사용자 흐름

1. 사용자가 `rpa.html`에서 `만족도 분석 & 보고서 생성기` 카드를 클릭한다.
2. `satisfaction-analyzer.html` 페이지로 이동한다.
3. 사용자는 다음 중 하나를 선택한다.
   - CSV 파일 업로드
   - 엑셀/구글시트/Tally 결과 표 복사 후 붙여넣기
4. 도구가 헤더와 행을 파싱한다.
5. 도구가 컬럼을 자동 분류한다.
   - 점수 문항
   - 주관식 문항
   - 메타 정보 컬럼
   - 개인정보 가능 컬럼
6. 사용자가 분석 제외/포함 컬럼을 확인한다.
7. `분석하기` 버튼을 누른다.
8. 결과 화면에 요약 지표, 문항별 카드, 주관식 응답 목록이 표시된다.
9. 사용자는 보고서 요약 텍스트를 복사하거나 결과 CSV를 다운로드한다.

## 6. UI 구성

### 6.1 상단

- 기존 홈페이지 헤더와 푸터 재사용
- 제목: `만족도 분석 & 보고서 생성기`
- 보조 문구: `CSV 업로드 또는 표 데이터 붙여넣기만으로 설문 결과를 브라우저에서 안전하게 분석합니다.`
- 개인정보 안내 문구는 짧게 표시
  - 예: `파일은 서버로 전송되지 않고 현재 브라우저에서만 처리됩니다.`

### 6.2 입력 영역

- 탭 또는 세그먼트 컨트롤
  - `CSV 업로드`
  - `표 데이터 붙여넣기`
- CSV 업로드 영역
  - 파일 선택
  - 드래그 앤 드롭은 선택 사항
  - `.csv`만 허용
- 붙여넣기 영역
  - textarea
  - 탭 구분/쉼표 구분 자동 판단
- 샘플 데이터 버튼
  - 개발 및 사용자 이해용
  - 실제 배포 시에도 유지 가능

### 6.3 컬럼 확인 영역

파싱 후 아래 표 또는 카드 목록을 보여준다.

- 컬럼명
- 자동 분류
- 분석 포함 여부
- 샘플 값 2~3개

자동 분류 값:

- `점수 문항`
- `주관식 문항`
- `메타 정보`
- `개인정보 가능`
- `분석 제외`

1차 버전에서는 컬럼 분류 수동 변경까지 넣으면 좋지만, 시간이 부족하면 개인정보 가능 컬럼만 자동 제외하고 나머지는 자동 분석해도 된다.

### 6.4 결과 요약

대시보드의 만족도 조회 화면에서 가져올 핵심 패턴:

- 요약 카드 4개
  - 응답 수
  - 점수 문항 수
  - 전체 평균
  - 긍정 응답률
- 선택 카드 1개
  - 추천 의향/NPS 후보 문항이 있으면 NPS 표시
  - 후보 문항이 없으면 `NPS 문항 미탐지` 표시

NPS는 1~5점 척도 기준으로 단순화한다.

- 5점: 추천 고객
- 4점: 중립
- 1~3점: 비추천
- NPS = 추천 비율 - 비추천 비율

### 6.5 문항별 카드

문항별로 카드 표시:

- 문항명
- 응답 수
- 평균
- 긍정 응답률
- 1~5점 분포 막대
- 낮은 점수 비율 경고

분포 막대는 대시보드의 `1~5점 누적 그래프` 아이디어를 활용한다. 별도 차트 라이브러리 없이 CSS 막대로 구현한다.

### 6.6 주관식 응답

- 문항별 아코디언 또는 리스트
- 빈 응답 제거
- 너무 긴 답변은 1차 표시 후 펼치기
- 복사 가능한 형태 유지

## 7. 데이터 파싱 규칙

### CSV

- 브라우저 `FileReader` 사용
- 외부 라이브러리 없이 직접 파싱
- 쉼표, 큰따옴표, 줄바꿈이 섞인 기본 CSV는 처리
- 복잡한 Excel 내보내기 CSV까지 완벽 대응하지 않아도 된다.

### 붙여넣기 표

자동 구분자 판단:

1. 탭 문자가 있으면 TSV로 처리
2. 탭이 없고 쉼표가 있으면 CSV로 처리
3. 둘 다 애매하면 줄 단위와 쉼표 개수 기준으로 판단

### 헤더

- 첫 행을 헤더로 사용
- 빈 헤더는 `컬럼 1`, `컬럼 2` 형식으로 대체
- 중복 헤더는 뒤에 번호를 붙여 내부 키를 구분

## 8. 컬럼 자동 분류 규칙

- 이름
- 성명
- 휴대폰
- 전화

- 이메일
- email
- mail
- 소속
- 회사
- 부서

- 주소

### 점수 문항

다음 조건을 만족하면 점수 문항으로 분류한다.

- 빈 값을 제외한 값의 70% 이상이 숫자
- 숫자 값 대부분이 1~5 범위
- 응답 개수가 3개 이상

문항명에 아래 키워드가 있으면 점수 문항 후보 가중치를 높인다.

- 만족
- 추천
- 이해
- 도움
- 강사
- 교육
- 운영
- 내용
- 난이도
- 전반
- 평가

### NPS 후보 문항

컬럼명에 아래 키워드가 있으면 NPS 후보로 잡는다.

- 추천
- 추천 의향
- NPS
- 순추천

후보가 여러 개면 첫 번째 후보를 사용하고, 결과 화면에 사용 문항명을 표시한다.

### 주관식 문항

다음 조건을 만족하면 주관식 문항으로 분류한다.

- 문자열 응답이 많음
- 평균 길이가 8자 이상
- 점수 문항이 아님
- 개인정보 가능 컬럼이 아님

컬럼명에 아래 키워드가 있으면 주관식 후보 가중치를 높인다.

- 의견
- 소감
- 좋았던
- 아쉬운
- 개선
- 기타
- 코멘트
- comment
- feedback

## 9. 분석 지표

### 전체 요약

- `response_count`: 전체 응답 행 수
- `score_question_count`: 점수 문항 수
- `text_question_count`: 주관식 문항 수
- `overall_average`: 모든 점수 문항의 평균
- `positive_rate`: 4점 이상 비율
- `low_score_rate`: 1~2점 비율
- `nps`: NPS 후보 문항이 있을 때만 계산

### 문항별 지표

- 응답 수
- 평균
- 중앙값
- 1점 수
- 2점 수
- 3점 수
- 4점 수
- 5점 수
- 긍정 응답률
- 낮은 점수 비율

중앙값은 선택 사항이다. 1차 구현 시간이 부족하면 평균과 분포만 구현해도 된다.

## 12. 상태 처리

### Ready

입력 방법을 선택할 수 있는 기본 상태.

### Parsing

파일 또는 붙여넣기 데이터를 읽는 중.

### Review

컬럼 자동 분류 결과를 보여주는 상태.

### Result

분석 결과를 보여주는 상태.

### Empty

데이터가 없거나 헤더만 있는 경우.

### Error

파싱 실패, 점수 문항 없음, 행/열 수 불일치 등의 경우.

에러 문구는 사용자가 수정할 수 있게 구체적으로 작성한다.

예:

- `첫 번째 행에서 컬럼명을 찾지 못했습니다.`
- `1~5점 척도 문항을 찾지 못했습니다. 점수 컬럼이 숫자로 입력되어 있는지 확인해주세요.`
- `CSV 따옴표 형식이 닫히지 않았습니다. 원본 파일을 다시 저장한 뒤 시도해주세요.`

## 16. QA 체크리스트

### 입력

- CSV 파일 업로드가 동작한다.
- 표 붙여넣기가 동작한다.
- 탭 구분 데이터가 동작한다.
- 쉼표 구분 데이터가 동작한다.
- 빈 행이 있어도 분석이 깨지지 않는다.
- 중복 헤더가 있어도 내부 처리가 가능하다.

### 분석

- 1~5점 문항을 자동 탐지한다.
- 개인정보 가능 컬럼을 기본 제외한다.
- 주관식 문항을 자동 탐지한다.
- 전체 평균이 올바르게 계산된다.
- 긍정 응답률이 올바르게 계산된다.
- NPS 후보 문항이 있을 때 NPS가 표시된다.
- NPS 후보 문항이 없을 때 안내가 표시된다.

### UI

- 결과 카드가 데스크톱에서 겹치지 않는다.
- 모바일에서 버튼 텍스트가 넘치지 않는다.
- 긴 문항명이 카드 밖으로 넘치지 않는다.
- 주관식 긴 답변이 레이아웃을 깨지 않는다.
- 오류 메시지가 사용자 행동으로 이어질 만큼 구체적이다.

### 출력

- 보고서 요약 복사가 동작한다.
- 분석 결과 CSV 다운로드가 동작한다.
- 다운로드 CSV가 UTF-8 BOM을 포함해 Excel에서 한글이 깨지지 않는다.

## 17. 구현 우선순위

### 1순위

- `satisfaction-analyzer.html` 생성
- CSV/붙여넣기 파싱
- 점수 문항 자동 탐지
- 요약 지표
- 문항별 분포 카드
- `rpa.html` 카드 연결

### 2순위

- 주관식 응답 그룹
- 개인정보 가능 컬럼 안내
- 보고서 요약 복사
- 결과 CSV 다운로드

### 3순위

- 컬럼 포함/제외 수동 조정
- 샘플 데이터 버튼
- 모바일 세부 polish
- `sitemap.xml` 추가

## 18. Gemini 작업 시 주의사항

- 신규 npm 패키지는 추가하지 않는다.
- SheetJS 등 외부 라이브러리는 1차에서 사용하지 않는다.
- 홈페이지 정적 배포 구조를 유지한다.
- 기존 TIFF 도구의 사용자 경험과 최대한 맞춘다.
- 대시보드의 내부 API 코드를 그대로 복사하지 않는다.
- 개인정보가 포함될 수 있는 원본 데이터를 서버로 전송하지 않는다.
- 구현 후 작업 요약을 커밋 메시지 또는 안내 텍스트로 남긴다.

## 19. Codex 검토 포인트

Gemini 구현 후 Codex는 다음 항목을 우선 검토한다.

- CSV 파서가 따옴표/쉼표/줄바꿈 기본 케이스를 처리하는지
- 점수 문항 자동 탐지가 과도하게 넓거나 좁지 않은지
- 개인정보 가능 컬럼이 결과 요약에 섞이지 않는지
- 모바일에서 카드/버튼/긴 문항명이 겹치지 않는지
- 다운로드 CSV 한글이 Excel에서 깨지지 않는지
- 서버 전송 코드가 실수로 들어가지 않았는지
