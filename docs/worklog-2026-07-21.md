## 2. 확인이 필요한 것

1. **가이드 폼의 기존 리드 회수** — 이전 엔드포인트(`AKfycbzbPLLNTIV9c1Ef...`)가 가리키던 시트에 접수된 리드가 남아 있을 수 있다. 가장 고관여 리드라 확인 가치가 크다.
2. **배포 확인** — GitHub Pages 반영 후 `datagongbang.kr/blog/ref-12.html` 접속과 구 URL 리다이렉트를 실제 도메인에서 한 번 봐 주면 좋다.
3. **Search Console** — 새 sitemap 제출 후 4주쯤 뒤 색인 페이지 수 변화를 보면 U1 수정 효과를 판단할 수 있다.

## 3. 일부러 하지 않은 것

- **회사소개서·교육제안서 PDF** — 전환 최대 병목이지만, 가격대·이력·사례 표현은 사실 확인이 필요해 임의로 만들 수 없다. 초안 구성은 로드맵에 적어 뒀다.
- **예산 범위 폼 항목** — 추가해도 GAS 시트에 해당 컬럼이 없으면 값이 조용히 사라진다. Apps Script 수정과 함께 가야 한다.
- **전화번호·카카오톡 채널** — 실제 번호와 채널 개설이 필요하다.
- **후기 실명화** — 당사자 동의가 필요하다.
- **네이버 verification 을 전 페이지에 추가** — 진단 때 "누락"으로 적었으나, 확인해 보니 **소유 확인은 루트에서만 하면 되고 하위 페이지 추가는 SEO 효과가 없다.** 불필요한 작업이라 하지 않았다.
- **줄바꿈 일괄 정규화** — 저장소에 CRLF/LF가 섞여 있다. 이번 커밋에 섞으면 리뷰가 불가능해져 손대지 않았다. `.gitattributes` 추가 + 별도 커밋으로 정리하는 게 맞다.
