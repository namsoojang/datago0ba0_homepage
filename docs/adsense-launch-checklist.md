# Google AdSense 출시 체크리스트

이 문서는 사이트 코드 정비 이후 AdSense 계정에서 완료해야 하는 운영 절차를 정리한다.

## 코드 반영 완료

- 개인정보처리방침에 Google 광고 쿠키, 맞춤 광고 설정, 제3자 광고 사업자 및 CMP 고지를 추가했다.
- 심사 기간 동안 광고 비중을 최소화하기 위해 쿠팡 파트너스 배너가 있던 4개 페이지에서 배너를 모두 제거했다.
- 최신 블로그 글 `ref-12`를 `sitemap.xml`에 추가했다.
- `robots.txt`는 전체 크롤링을 허용하며 사이트맵 주소를 제공한다.

## AdSense 계정 생성 후 완료

1. AdSense의 **사이트** 메뉴에서 `datagongbang.kr`을 추가한다.
2. Google이 제공한 게시자 확인 코드 또는 메타 태그를 공통 `<head>`에 삽입한다.
3. **개인정보 보호 및 메시지**에서 유럽 규정 메시지를 만든다.
4. Google CMP의 동의 옵션은 `동의`, `동의하지 않음`, `옵션 관리`의 3개 버튼 구성을 사용한다.
5. CMP 메시지 대상 사이트가 `datagongbang.kr`인지 확인하고 게시한다.
6. 사이트 소유권 확인 후 검토를 요청한다.
7. 승인 후 AdSense가 제시한 게시자 ID로 루트의 `ads.txt`를 만든다.

`ads.txt` 예시(실제 게시자 ID 발급 전에는 추가하지 않는다):

```text
google.com, pub-발급받은게시자ID, DIRECT, f08c47fec0942fa0
```

## 광고 배치 원칙

- 변환, 분석, 다운로드, 양식 제출 버튼 근처에는 광고를 배치하지 않는다.
- 광고를 메뉴, 결과 또는 도구 기능으로 오인할 수 있는 위치에 배치하지 않는다.
- 광고 및 제휴 콘텐츠의 양이 페이지 고유 콘텐츠보다 많아지지 않게 한다.
- 운영자 본인이 광고를 클릭하거나 클릭을 요청하지 않는다.
