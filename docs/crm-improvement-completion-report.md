# 데이터공방 CRM 홈페이지 개선 완료 보고서

작성일: 2026-07-18

## 완료 범위

1. 전 페이지 글로벌 메뉴 통일
2. 기업 교육 담당자 중심 Hero와 이중 CTA 정리
3. 공개 근거 기반 대표 교육 사례 3건 구조화
4. 교육·자동화·가이드·사례의 방문 목적별 경로 추가
5. STEP 01 → STEP 02 → 팀 상담과 PDF 직접 다운로드 흐름 보강
6. 문의 필수값 최소화, 개인정보 동의, 유입 맥락 저장 보완
7. 적합성·진행·보안·비용 관련 FAQ 8개 추가
8. 개인정보 없는 GA4 CRM 퍼널 이벤트 명세와 구현
9. 링크, HTML ID, JavaScript, 폼 레이블과 모바일 반응형 회귀 점검

## 검증 결과

- 실제 서비스 HTML의 로컬 링크와 이미지 경로 오류 없음
- 중복 HTML ID 없음
- `modules/*.js` 구문 검사 통과
- 문의 폼은 이메일·문의 맥락·동의를 핵심 필수값으로 사용
- GA4 이벤트에서 이름, 이메일, 전화번호, 회사명, 자유 입력 내용을 제외
- 사례 카드는 데스크톱 3열, 모바일 1열로 확인
- FAQ는 네이티브 `details/summary`를 사용해 키보드 조작 가능

## 배포 전 확인

- GitHub `review/codex`를 `main`에 병합해야 서버 배포 대상이 된다.
- GA4 DebugView에서 실제 이벤트가 한 번씩 수집되는지 확인한다.
- Apps Script가 새 필드 `interest`, `privacy_consent`, `source_page`, `source_url`, `referrer`, `submitted_at`을 저장하는지 확인한다. 알 수 없는 필드를 무시하는 경우 서버 스키마 보완이 필요하다.
- 기존 기관 로고의 공개 사용 권한과 후기 원문 보관 위치를 운영자가 확인한다.
