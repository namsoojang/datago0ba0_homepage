# 슬랙 편지배달부 앱 업데이트: 백그라운드 안정성 및 버전 관리 탑재

![슬랙 편지배달부 앱 업데이트](./assets/images/blog/smsforwarder_update_cover.png)

공용 폰의 중요 문자 및 부재중 전화, 카카오톡 문의를 실시간으로 슬랙 채널에 안전하게 배달해 주던 **‘슬랙 편지배달부’** 안드로이드 네이티브 앱의 최신 패치(v1.0.1) 업데이트 소식을 전해드립니다.

이번 업데이트는 실제 스마트폰 기기에서 구동되면서 발견된 백그라운드 서비스 동작 제어 결함 수정과 함께, 지속적인 배포 편의성을 높이기 위한 자동화 시스템 도입에 초점을 맞췄습니다.

## 1. 작동 중지 기능의 안정성 완벽 확보

기존 버전에서는 사용자가 설정 수정 및 동작 일시 정지를 위해 메인 화면의 **[중단하기]** 버튼을 누르더라도, 백그라운드에서 백그라운드 리스너와 브로드캐스트 수신기는 계속 작동하여 중요 문자나 카카오톡이 수신되면 슬랙 웹훅으로 전송을 시도하는 현상이 있었습니다.

이는 메인 UI에서는 제어권이 풀려 수정 상태로 들어가지만, 백그라운드 감지 코드는 여전히 활성화된 스위치 상태만을 대조하여 발생한 제어 상태기계의 불일치였습니다.

* **개선 사항**: 이제 [SmsNotificationListenerService](file:///c:/Users/장남수/Documents/00_데이터공방/Project/문자메세지자동전달/android_project/app/src/main/java/com/company/smsforwarder/SmsNotificationListenerService.kt), [SmsReceiver](file:///c:/Users/장남수/Documents/00_데이터공방/Project/문자메세지자동전달/android_project/app/src/main/java/com/company/smsforwarder/SmsReceiver.kt), [CallReceiver](file:///c:/Users/장남수/Documents/00_데이터공방/Project/문자메세지자동전달/android_project/app/src/main/java/com/company/smsforwarder/CallReceiver.kt) 등 모든 백그라운드 수신 필터 단계에 **'설정 잠금 상태(isSettingsLocked)'** 검증 절차를 추가했습니다.
* **체감 효과**: [중단하기]를 눌러 락이 풀려 대기 상태가 되는 순간, 시스템에서 어떠한 문자가 수신되더라도 즉시 배달 프로세스를 중단(Skip)하고 휴식 상태를 지켜냅니다. 오직 다시 [자동 배달 등록] 버튼을 눌러 초록색 **배달 중** 램프가 켜졌을 때만 실시간 전송이 가동됩니다.

## 2. 깃허브 빌드 배포 자동화 및 버전 일시 매핑

사용자들이 최신 버전을 설치할 때 언제 빌드된 파일인지 한눈에 알고 관리할 수 있도록 GitHub Actions CI/CD 파이프라인의 빌드 파일 네이밍 체계를 개선했습니다.

* **버전 및 시간 변수 동적 주입**: 깃허브 Actions로 클라우드 빌드가 돌아가는 시점의 한국 표준시(KST)를 추출하고, 안드로이드 빌드 구성(`build.gradle`)에 정의된 실시간 버전 이름을 자동으로 파싱해 환경변수로 주입합니다.
* **버전 날짜 직관화**: 빌드 성공 후 생성되는 APK 파일과 압축 파일의 이름을 기존 `메세지배달부-debug.apk`에서 **`메세지배달부-v1.0.1-20260620_1643.apk`**와 같이 버전에 맞춰 동적 생성하도록 개선했습니다.
* **설치 편의성**: 언제 빌드된 릴리즈이자 어떤 버전인지 파일명만으로 즉시 판별이 가능하여 버전 관리가 매우 용이해졌습니다.

## 3. 정식 버전 관리 체계 도입 (v1.0.0 ➡️ v1.0.1)

이번 업데이트를 기점으로 본격적인 시맨틱 버전 관리(Semantic Versioning)를 가동합니다.
안드로이드 앱 패키지의 `versionCode`를 `2`로, `versionName`을 `1.0.1`로 공식 범프하여 버전 일치성을 확보하고, 프로젝트 루트에 변경 이력을 체계적으로 투명하게 기록해두는 `CHANGELOG.md`를 신설하여 향후 유지보수가 더욱 매끄럽도록 정돈했습니다.
