## 🛠️ 준비 작업 (환경 구성)

파이썬이 컴퓨터에 설치되어 있지 않더라도 괜찮습니다. 구글에서 제공하는 웹 브라우저 코딩 도구인 **구글 코랩(Google Colab)**을 켜시면 별도의 설치 없이 바로 실습해 보실 수 있습니다.

먼저, 파이썬에서 엑셀 데이터를 다루기 위해 가장 핵심이 되는 라이브러리를 임포트(import)합니다.

```python
import os
import pandas as pd
```

---

## 💻 엑셀 병합 핵심 코드 (3 Lines)

합치고자 하는 엑셀 파일들을 특정 폴더(예: `excel_files`)에 모아놓았다고 가정해 보겠습니다. 

```python
# 1. 특정 폴더 내의 모든 엑셀 파일(.xlsx) 경로 리스트 만들기
folder_path = './excel_files/'
excel_files = [os.path.join(folder_path, f) for f in os.listdir(folder_path) if f.endswith('.xlsx')]

# 2. 모든 엑셀 파일을 읽어서 리스트에 넣고 하나로 이어 붙이기
combined_df = pd.concat([pd.read_excel(file) for file in excel_files], ignore_index=True)

# 3. 병합된 최종 결과를 새로운 엑셀 파일로 출력하기
combined_df.to_excel('final_merged_report.xlsx', index=False)
```

### 💡 코드 상세 설명
* `os.listdir()`: 지정한 폴더 내의 모든 파일명을 긁어옵니다.
* `f.endswith('.xlsx')`: 엑셀 파일만 걸러내어 안전성을 보장합니다.
* `pd.read_excel(file)`: 개별 엑셀 파일을 메모리 상으로 가져옵니다.
* `pd.concat([...])`: 리스트에 적재된 모든 엑셀 데이터를 아래 방향으로 한꺼번에 합쳐 줍니다.
* `ignore_index=True`: 개별 파일의 행 인덱스(0, 1, 2...)를 합치면서 번호가 꼬이지 않도록 순서대로 초기화해 줍니다.

## ⚡ 추가 꿀팁: 데이터 중복 제거 및 가공

파일들을 단순히 합치기만 하면 중복 데이터가 발생할 수 있습니다. 예를 들어, 동일한 주문 번호나 사원 번호가 중복 등록된 데이터를 삭제하려면 아래의 한 줄을 추가하면 됩니다.

```python
# '주문번호' 열을 기준으로 완벽히 겹치는 중복 행 제거 (가장 최신 데이터 보존)
cleaned_df = combined_df.drop_duplicates(subset=['주문번호'], keep='first')
```
