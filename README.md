# 데이터공방 공식 홈페이지 (DATAGO0BA0 Homepage)

대기업 및 기관 교육 담당자(HRD)를 타겟으로 하여, 데이터공방의 브랜드 정체성과 교육 전문성, 그리고 화려한 출강 레퍼런스를 전달하기 위해 구축된 프리미엄 1페이지 포트폴리오 홈페이지 및 무료 업무 자동화(RPA) 포털 서비스입니다.

---

## 🎨 주요 디자인 및 기능적 특징

> 디자인 기준 문서는 루트의 `DESIGN.md`를 우선 참조합니다. 신규 페이지/컴포넌트는 `index.css`의 의미 기반 CSS 토큰과 `DESIGN.md`의 색상, 타이포그래피, 컴포넌트 규칙을 기준으로 구현합니다.

### 1. 세련된 비주얼 시스템 (Smart Teal & Deep Navy / Pure White)
* **메인 홈페이지**: 깊고 진중한 신뢰감을 주는 딥네이비/블루 (`#0B132B`, `#080E1E`) 배경에 글래스모피즘(Glassmorphism) 효과를 가미하여 프리미엄 B2B 교육 브랜드 정체성을 투영했습니다.
* **RPA 자동화 허브 및 도구**: 흰색 배경의 쿠팡 파트너스 배너 광고와의 완벽한 시각적 조화 및 실무 도구로서의 쾌적한 사용성을 극대화하기 위해, 까만 그라디언트를 걷어낸 **순백색(Pure White, #FFFFFF) 라이트 테마**를 전격 적용했습니다.

### 2. 5대 프리미엄 애니메이션 패턴 (GSAP & CSS)
* **Hero Entrance (GSAP Timeline)**: 첫 로딩 시 문장들과 프로필 카드가 자연스럽게 시간차를 두고 순차 등장합니다. `gsap.set()` 적용으로 로딩 시의 깜빡임(FOUC)을 방지했습니다.
* **Mouse Parallax (입체 패럴랙스)**: 마우스 커서의 움직임에 따라 메인 프로필 카드와 배경의 기하학 도형들이 서로 다른 속도로 반응하여 깊이 있는 입체감을 줍니다.
* **Scroll-triggered Reveals (3D 스크롤 리빌)**: 핵심 강점(Why Us) 영역으로 스크롤할 때 카드들이 3D 틸트(`rotateX: 18deg`)를 그리며 순차적으로 드러납니다.
* **Floating Shapes (CSS 배경 애니메이션)**: 배경의 추상 기하학 도형들이 브라우저 GPU 가속을 활용해 끊임없이 부드럽게 스스로 유영하며 동적인 느낌을 줍니다. (라이트 테마에서는 투명도를 3%로 낮춰 은은한 텍스처로 제공)
* **Scroll Indicator (바운스)**: 메인 하단에 화살표가 위아래로 부드럽게 바운스하며 스크롤을 유도합니다.

### 3. 실무 지향적 인터랙션 & 무료 업무 도구
* **무료 TIFF to PNG 변환기**: 고용량 TIFF 그래픽 파일을 서버 전송(개인정보 유출 방지) 없이 100% 브라우저단에서 안전하고 고화질로 일괄 변환(ZIP 패키징 다운로드 지원)하는 강력한 로컬 유틸리티를 제공합니다.
* **Coming Soon 알림 예약**: 개발 중인 자동화 도구들(만족도 분석기, 수신거부 필터, 카페 등록기)에 대한 사전 알림 신청 모달 시스템이 탑재되어 있습니다.
* **완료 알림 중앙 성공 모달**: 이메일 문의 접수 및 사전 예약 완료 시, 우측 하단의 작은 토스트 대신 화면 중앙에 반투명 오버레이와 **SVG 체크마크 드로잉 애니메이션**이 가미된 세련된 대형 완료 팝업창을 출력합니다.

## 🛠️ 실행 및 배포 방법

### 로컬 실행
정적 웹사이트 구조이므로 `index.html` 또는 `rpa.html` 파일을 웹 브라우저에 직접 더블클릭하여 실행하시거나, 아래와 같이 로컬 호스트로 띄워 완벽하게 테스트할 수 있습니다.
```powershell
python -m http.server 8000
```

### 도메인 및 호스팅 연동
추가 서버 비용 없이 평생 무료로 호스팅할 수 있도록 설계되어 있습니다.
* **GitHub Pages**: `Settings > Pages`에서 커스텀 도메인(CNAME)을 연동하여 빠르게 도메인을 연결할 수 있습니다.
* **Cloudflare Pages**: 깃허브 저장소를 연동해 두면 코드 Push 시 자동으로 글로벌 CDN 배포가 완료되며, 손쉬운 도메인 연결 및 SSL 연동이 완료됩니다.
