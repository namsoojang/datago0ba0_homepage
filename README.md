# 데이터공방 공식 홈페이지 (DATAGO0BA0 Homepage)

대기업 및 기관 교육 담당자(HRD)를 타겟으로 하여, 데이터공방의 브랜드 정체성과 교육 전문성, 그리고 화려한 출강 레퍼런스를 전달하기 위해 구축된 프리미엄 1페이지 포트폴리오 홈페이지입니다.

---

## 🎨 주요 디자인 및 기능적 특징

### 1. 세련된 비주얼 시스템 (Smart Teal & Deep Navy)
* **메인 컬러**: 깊고 진중한 신뢰감을 주는 딥네이비/블루 (`#0B132B`, `#080E1E`)
* **포인트 컬러**: 지적이고 트렌디한 인공지능/데이터 분석 테마의 세이지 틸 (`#00A896`, `#02C39A`)
* **스타일**: 미세한 반투명 보더와 블러 필터를 가미한 **글래스모피즘(Glassmorphism)** 효과로 세련된 카드 UI를 연출했습니다.

### 2. 5대 프리미엄 애니메이션 패턴 (GSAP & CSS)
* **Hero Entrance (GSAP Timeline)**: 첫 로딩 시 문장들과 프로필 카드가 자연스럽게 시간차를 두고 순차 등장합니다. `gsap.set()` 적용으로 로딩 시의 깜빡임(FOUC)을 방지했습니다.
* **Mouse Parallax (입체 패럴랙스)**: 마우스 커서의 움직임에 따라 메인 프로필 카드와 배경의 기하학 도형들이 서로 다른 속도로 반응하여 깊이 있는 입체감을 줍니다. (모바일 등 터치 디바이스에서는 자동 비활성화)
* **Scroll-triggered Reveals (3D 스크롤 리빌)**: 핵심 강점(Why Us) 영역으로 스크롤할 때 카드들이 3D 틸트(`rotateX: 18deg`)를 그리며 순차적으로 드러납니다.
* **Floating Shapes (CSS 배경 애니메이션)**: 배경의 추상 기하학 도형들이 브라우저 GPU 가속을 활용해 끊임없이 부드럽게 스스로 유영하며 동적인 느낌을 줍니다.
* **Scroll Indicator (바운스)**: 메인 하단에 화살표가 위아래로 부드럽게 바운스하며 스크롤을 유도합니다.

### 3. 실무 지향적 인터랙션
* **커리큘럼 탭 전환**: AI/AX, Python, Excel 세 가지 대표 코스의 세부 요강을 매끄러운 페이드인 전환 효과로 볼 수 있습니다.
* **출강 레퍼런스 필터**: 대기업, 공공·금융, 대학교 카테고리별로 로고 그리드를 신속하게 필터링하여 제공합니다.
* **이메일 주소 간편 복사**: 이메일 주소 복사 시, 클립보드에 복사 완료된 후 화면 우측 하단에 세련된 커스텀 토스트 알림(Toast UI)이 표시됩니다.

## 🛠️ 실행 및 배포 방법

### 로컬 실행
`index.html` 파일을 웹 브라우저에 직접 드래그 앤 드롭하여 실행하시거나, VS Code의 Live Server 등을 활용하여 간편하게 로컬 호스트로 띄워 테스트할 수 있습니다.

### 도메인 및 호스팅 연동
정적 웹사이트 구조이므로 **GitHub Pages** 또는 **Cloudflare Pages**를 통해 별도의 서버 비용 없이 평생 무료로 호스팅할 수 있습니다.
* **GitHub Pages**: `Settings > Pages`에서 커스텀 도메인(CNAME)을 연동하여 빠르게 도메인을 연결할 수 있습니다.
* **Cloudflare Pages**: 깃허브 저장소를 연동해 두면 코드 Push 시 자동으로 글로벌 CDN 빌드 및 배포가 완료되며, 간편한 도메인 설정이 가능합니다.
